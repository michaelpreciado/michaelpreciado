## What I’m building now

**Preciado Tech** — automation help for busy small businesses.

I’m focused on the useful, unglamorous work that saves real time:

- turning website forms into organized lead lists
- sending follow-up emails and reminders before things slip
- cleaning up spreadsheet-heavy workflows
- drafting customer replies, summaries, and updates faster
- moving information between tools without copy-paste
- building small internal tools that are easy to understand
- polishing websites so customers know what to do next

My taste is simple: fewer moving parts, plain language, and tools people actually keep using.
