## What I build

- **Local AI command centers** — FRIDAY. Agents, memory, and automation running on my own hardware
- **Robotic systems** — OpenClaw. Dual 6-DOF arms, ESP32-S3, MicroPython, real motion control
- **Polished web tools** — React/Next.js apps that look good and survive real traffic
- **Automation infrastructure** — Bots, pipelines, and integrations that actually keep running

Running everything on Arch Linux with an RTX 5080 and enough GPUs to make Ollama happy.

## Currently working on

**FRIDAY** — a local first AI agent crew. Telegram gateway, Obsidian vault memory, stock trading bots, and a Mission Control dashboard. Think Jarvis but self hosted and opinionated.

**OpenClaw** — dual robotic arm on ESP32-S3. 12 servos, time division multiplexed LEDC, FastAPI relay, voice control through Tailscale. Hardware I designed, firmware I wrote, software I stitched together.
